Propuesta de Desarrollo Web

🎯 Objetivo del Proyecto

Crear un sitio web moderno, responsivo y enfocado en exhibir productos con acceso rápido a contacto mediante WhatsApp, permitiendo escalarlo a funciones de tienda online a futuro.

📋 Alcance del Proyecto

Estructura del Sitio

  • Página principal con productos destacados
  • Sección de productos con imágenes y precios
  • Subpáginas de categorías
  • Página de contacto
  • Botón fijo de WhatsApp en todo el sitio
  • Diseño adaptable (móvil, tablet y escritorio)
  • Carga inicial de hasta 50 productos

💻 Tecnologías

Sitio Estático

  • Frontend: HTML, CSS, JavaScript
  • Integración: WhatsApp / WhatsApp Business
  • Base de datos: SQL para gestión de inventario
  • Escalabilidad: Preparación para transición futura a carrito de compras

📦 Entregables

  • ✅ Sitio web funcional y publicado
  • ✅ Video manual básico para agregar/modificar/eliminar inventario
  • ✅ Gestión de imágenes y textos en base de datos SQL
  • ✅ Copia de seguridad del proyecto completo

⏱️ Plazos Estimados

Fase 1: Diseño

Diseño y estructura visual: 3 días hábiles

Fase 2: Desarrollo

Desarrollo + carga de productos: 4-6 días hábiles

Fase 3: Finalización

Revisión y ajustes finales: 2 días hábiles

9-11 días hábiles
